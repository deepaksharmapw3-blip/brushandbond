TROUBLESHOOTING
───────────────

Image not showing?
  → Check file path is exact: hero-building.jpg
  → Verify folder: public/images/
  → Hard refresh browser: Ctrl+Shift+R
  → Check console (F12) for 404 errors

Python script fails?
  → Make sure Python installed: python --version
  → Try from brushandbond folder
  → Pillow auto-installs if needed

WebP not loading?
  → JPEG fallback should work
  → Browser supports WebP (Chrome, Firefox, Safari, Edge)
  → Check file sizes are reasonable

Text not readable?
  → Overlay gradient is dark enough
  → Increase opacity in HeroBackdrop.tsx if needed
  → Check monitor brightness
